# Decisions

Architecture decision records. Each says what was decided, why, and, where it
matters, what was measured. They are records: a later change of mind is a new
record or a dated amendment, not an edit.

| | |
|---|---|
| [0001](0001-no-dependencies.md) | uniTube takes no dependencies |
| [0002](0002-two-level-ir.md) | The path IR has two levels |
| [0003](0003-licence.md) | BSD-2-Clause; prior art quarantined |
| [0004](0004-no-mitres.md) | `r = 0` at an interior vertex is an error |
| [0005](0005-terminations-are-separate.md) | Terminations are a separate library; uniTube ships a port record |
| [0006](0006-profile-correspondence.md) | Profile loops must be correspondence-aligned |
| [0007](0007-open-annulus.md) | A C-section is an open annulus, not one closed loop |
